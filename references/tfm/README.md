# TFM reference

Este directorio se reserva para el material del TFM, conservado como referencia histórica de la línea de investigación.

## Qué incluir

- documento final del TFM (PDF o versión editable)
- anexos relevantes
- notas metodológicas del TFM
- screenshots o exportaciones de resultados clave
- snapshots de scripts o datos experimentales si son útiles como historial

## Qué no debe hacerse

- no mezclar el desarrollo del doctorado con el material del TFM
- no asumir que los scripts del TFM son la última versión del modelo científico
- no usar el TFM como directorio operativo del doctorado

## Regla de trazabilidad

Todo material del TFM debe estar claramente identificado con:

- título del TFM
- autor/a
- fecha
- curso o periodo académico
- notas de contexto de uso
