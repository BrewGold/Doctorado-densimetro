# Referencias y material histórico

Este directorio recoge documentación de referencia del trabajo previo, sin mezclarlo con el desarrollo activo del doctorado.

## Estructura

- `tfm/`: material del TFM, incluido documento, anexos y snapshots del proyecto si procede.
- `papers/`: artículos, notas o referencias bibliográficas relevantes.
- `notes/`: observaciones internas del proyecto.

## Regla de uso

- El material del TFM se conserva para consulta, trazabilidad y contexto histórico.
- El desarrollo activo del doctorado debe mantenerse en `doctorado_sim/` y en la documentación técnica asociada.
- Cuando se reutilice contenido del TFM, se debe documentar explícitamente qué parte se incorpora al modelo doctoral y bajo qué hipótesis.
