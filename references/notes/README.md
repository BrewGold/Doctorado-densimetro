# Notas internas

Este directorio se usa para observaciones internas del proyecto doctoral.

## Uso recomendado

- decisiones de diseño
- acuerdos de modelado
- pendientes técnicos
- hipótesis de trabajo
- resultados preliminares que aún no se consolidan en documentación formal

## Importante

Este espacio no sustituye la documentación formal de `doctorado_sim/docs/`; sirve como cuaderno técnico auxiliar.
